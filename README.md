## 실행 방법

**온라인에서 바로 쓰기: https://aebonlee.github.io/data09-11/**

내 PC에서 쓰려면 설치 없이 아래 두 방법 중 하나로 엽니다.

1. **파일로 바로 열기** — 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. 인터넷이 없어도 동작합니다(엑셀 라이브러리도 `vendor/` 에 들어 있습니다). 사내 망에서 쓰기에 가장 알맞은 방법입니다.
2. **간이 서버로 열기** — 폴더에서 `python3 -m http.server 8000` 을 실행하고 브라우저에서 `http://localhost:8000` 을 엽니다.

처음 열면 데이터가 비어 있습니다. 현황 화면의 **「예시 데이터 불러오기」** 를 누르면 시연용 가상 데이터(기종 3개·공통 단계 5개·일정·이슈·자료·Bench Marking 1건)가 들어가고, 화면 위에 「예시 데이터」 안내 띠가 표시됩니다.

- 데이터는 **이 브라우저(localStorage)에만** 저장되고, 외부 서버나 외부 AI로 보내지 않습니다. 보관·이동은 「데이터」 메뉴의 엑셀 내보내기/가져오기로 합니다.
- 개발 기종 일정 Excel 은 「일정 가져오기」 메뉴에서 올립니다. 열 이름이 달라도 짝 맞추기 화면에서 맞출 수 있습니다.
- 예시 파일(모두 가상 데이터): `samples/예시데이터_개발일정.xlsx`·`.csv`(일정 가져오기 연습용, 일부러 다른 열 이름), `samples/예시데이터_전체.xlsx`(전체 내보내기 형식)
- 로직 테스트: `node test/logic.test.mjs` (의존성 없음)
- 예시 파일 다시 만들기: `node scripts/make-samples.js`
